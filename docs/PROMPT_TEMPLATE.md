# PROMPT_TEMPLATE.md — 分阶段执行指令模板

> **用途**：开新对话或新会话时，把「本文件 + 选题卡 + 一条规范摘要」交给编码代理，让它按同一套标准产出。
> **不参与规范裁决**：与 `AGENTS.md` / `STYLE_B_SILENT_VIBE.md` 冲突时，以规范为准。

---

## 一、给执行方的最小上下文

每次只装载这四样，不要带其它片子的脚本、分镜或帧数据：

1. `docs/AGENTS.md`（硬规则、目录、交付白名单）
2. `docs/STYLE_B_SILENT_VIBE.md`（2K 画幅、节奏、排版、编码、6 项验收）
3. `topics/<slug>.md`（本片选题卡，七字段齐全）
4. 本片的 `beats.json`（分幕时间轴）

> 1 个选题 = 1 条独立视频 = 1 个独立会话。禁止同一会话连渲多条全片。

## 三、阶段 1 · 核查与分幕定稿（不写代码）

```text
读取 docs/AGENTS.md 与 docs/STYLE_B_SILENT_VIBE.md，基于 topics/<slug>.md 执行，不写任何动画代码。

① 一手核查：论证链每个年份、研究者、文献、上屏数值与公式都给可点击 URL；
   一手直接用，二手明确标注；查不到出处的条目删除并报告删了什么。
   历史档案 / 公版手稿素材同步完成来源与版权判定。
② 隐喻自检：天平轻重、斜面倾斜、杠杆支点、卡爪开合、滚轮进位逐条核对方向是否与命题一致。
③ 变量表（缺项提问，不得自行编造）：
   片名 / 一句话命题 / 答案 / 论证链 / 主视觉母题 / lighting / asset_layers / 边界声明。
④ 分幕设计：
   主句 6–18 字（硬上限 22）；单幕时长 4.4–5.2（过场）/ 5.8–7.2（推导）/ 7.0–8.5（奇观）；
   句间空拍 0.50–0.90s；步间停顿 0.65–0.85s；反转前 0.35–0.50s；
   硬切清单、微音效表、BGM Drop 对齐秒数；Σ durationSec ∈ [75,140]（长片 [140,240]）。
输出：核查清单 + 隐喻自检 + 变量表 + 分幕表 + 音效表。到此停止，等定稿确认。
```

## 四、阶段 2 · 快审片（强制停等）

```text
以阶段 1 定稿为唯一基准。只渲染前 25–35 秒：720×1280 @ 30fps，
用 tools/mix_bgm.py --preview-duration 30 直接带 BGM + SFX 出片。

附：
- 非硬切交界 seam_delta 逐幕读数；
- 静态文字包围盒抽样（阅读窗内）；
- 2K 关键帧静图：核心道具特写 / 文字尾迹中段 / 中后段高潮结构；
- 一张 360px 逻辑宽的「手机实看缩略模拟图」。
到此停止，等点头；未点头不得渲染全片。
```

## 五、阶段 3 · 全片与验收

```text
流式渲染 1440×2560 @ 60fps 全片（帧不落盘）：
① 编码严格按 STYLE_B §5.0：
   -c:v libx264 -profile:v high -level:v 5.1 -pix_fmt yuv420p -crf 16 -preset slow -g 120 -movflags +faststart
   严禁 slice-max-mbs、全 I 帧、slices=NN、阅读窗像素复制。
② 定点抽帧（每幕阅读窗 3–4 帧 + 非硬切交界成对帧），跑 text_box_diff === 0.000 与 seam_delta。
③ tools/mix_bgm.py 出唯一成品 <主题>.mp4 + src/sfx_only.wav + bgm_mix_report.json；
   确认 bgm_gap_check.pass = true、climax_error_sec ≤ 0.03。
④ 跑齐 6 项验收；第 6 项 tools/decoder_check.py --strict 对唯一成品跑 1 次，
   PASS 后落盘 src/decoder_check.json。
⑤ 成品与报告全部落在 .work/ 之外且可读后，清理本期 .work/。
未通过项如实报告并修复复验，不得宣称完成。输出后停止。
```

## 六、硬指标速查

| 项 | 值 |
|---|---|
| 画幅 / 帧率 | `1440×2560` @ `60fps` |
| 编码 | H.264 `High@5.1` / `yuv420p` / `crf 16` / `preset slow` / `-g 120` / `+faststart` |
| 安全区 | `x:120–1212, y:240–2000` |
| 上层主句 | `y:306–694`，Bold `104/98/90px`，辅行 `76px` |
| 中层舞台 | `y:720–1866`，标注 Medium `≥44–48px`、亮度 `≥#CFC7B8` |
| 下层读数 | `y:1880–1980`，Mono `40–42px` |
| 线宽 | L1 `4.5–8.0` / L2 `3.5–4.5` / L3 `≥2.5px`（opacity `≥0.38`） |
| 死帧 | ROI `y:720–1866`，`roi_delta<0.05`，连续 `≤1.80s` |
| 文字 | 气口 `0.35–0.55s` → 入场 `0.38–0.45s` → 定格 `0.90–1.25s` → 出场 `0.60–0.72s` |
| 句间空拍 | `0.50–0.90s` |
| 音频 | 禁 `-an`；真峰值 `≤-1.0 dBTP`；`[0.5s,total-2.0s]` 无 `>1.5s` BGM 断层 |

## 七、禁止项

1. 按幕拆分独立重置组件；异构换场强留残缺旧边框。
2. 用平移雾条、旋转大尘盘、短周期扫光刷帧差。
3. 把核心机制藏在底部小字里，中层只放装饰几何。
4. 给静止文字加微晃；为压 H.264 误差改编码器。
5. 未过快审直接渲全片；整片 PNG 序列落盘。
6. 滚动数字横跳、数值提前卡死终值、标签压刻度、小屏易混字符（如 `½`）。
7. 编造事实、口头补数据、把二手聚合稿当一手来源。
