## 二、全频道统一的不变护栏（保证品牌辨识度与技术零事故）

### 2.1 技术硬底线（`hard`，由 `tools/profiles/` + `tools/episode.py` 程序死卡，不可覆盖）
- **画幅与编码**：正片原生 `1440×2560 @ 60fps`（禁 CSS 整体 `scale`），H.264 `High@5.1` / `yuv420p` / `BT.709` / `crf 16` / `preset slow` / `-g 120` / `+faststart`；快审（`preview`）`720×1280 @ 30fps`，只渲前 `25–35s`（带 BGM + SFX）。
- **零事故硬指标**：D3D11VA 硬解 `maxFrameMAE = 0`、`maxSampleDelta = 0`、`grayBlocks = 0`、全片单切片；阅读定格窗无损 PNG 静态文字框 `text_box_diff === 0.000`；非硬切交界无跳变（`seam_delta ≤ 0.01` 且 `max_pixel_delta ≤ 2` 且变动像素 `≤ 0.01%`，文字框零差不适用此容差）。
- **音频红线**：集成响度 `-18`～`-14 LUFS`、真峰值 `≤ -1.0 dBTP`、全片 `[0.5s, total-2.0s]` 无 `> 1.5s` BGM 断层、高潮对齐误差 `≤ 0.03s`；SFX 立体声母带非静音且峰值 `[-16, -12] dB`（单声道经 `-ac 2` 上混会掉 `-3.01 dB`）。
- **空间与可见性**：2K 安全区 `x: 120–1212, y: 240–2000`；中层 ROI（`y: 720–1866`）10fps 抽帧 `roi_delta < 0.05` 连续静止 `≤ 1.80s`（片尾最后 `1.5s` 除外）；光场占比达标（`studio_dark` 底色灰度 `< 40` 占 `[84%, 95%]`；`keynote_light` 底色灰度 `> 210` 占 `[72%, 92%]`）；手机端辅助线（L3）硬下限 `≥ 2.5px`、关键标注字号清晰高对比。

### 2.2 品牌统一骨架（极简秩序，不限制内容表达）
- **统一离线字库（4 族 8 文件，SIL OFL 1.1，`core/vibe 1.2.0` 默认内置，缺文件必报错禁回退系统字）**：
  - 上层大字：西文/数字 `Source Serif 4`（400/600）+ 中文 `寒蝉锦书宋`（`ChillJinshuSong` 400/700）；
  - 中层盘面标注：`Noto Sans SC`（400/500）；公式与等宽读数：`JetBrains Mono`（400/500，`tabular-nums`）。
- **统一版式秩序与画面纯净**：
  - 三层防打架分工：上层主句（常规 `y: 306–694`，主辅行有明确字阶与字重反差，单行 `≤ 12 字` 最多 2 行，中西混排 `0.15em` 微距，禁 `½` 统一写 `1/2`）、中层主舞台（`y: 720–1866`）、下层读数（`y: 1880–1980`，按需出现）——顶层主句与底层读数物理隔离于中层摄影机容器之外；开场、高潮与片名卡可按需居中破格（`y: 1040–1360`）；
  - **画面零杂音**：禁进度条、底部字幕带、矩形卡片框、角标水印、免责声明、常驻文献框与求赞引导；第 0 帧直接入戏不黑屏淡入；
  - **克制质感**：宏观极简、微观精工、同屏单焦点、低饱和高级色（禁纯白纯黑与高饱和霓虹）、禁廉价匀速与过冲回弹（`overshootClamping: true`）、禁抢戏倍速扫光（环境流光线速度 `≤ 95px/s`、`opacity ≤ 0.20`）。

## 三、每期自由定制区（`Creative` + `defaults`，严禁套模版！）

以下维度**不设唯一标准答案**，每期必须根据选题气质独立选型，避免与前作雷同：

1. **视觉媒介与核心元素库（按需选型或混合，绝不强行照搬旧片道具）**：
   - **实物材质系**：程序化 PBR 2× 超采样精灵（金属/玻璃/木石/纸张）+ 双层接触阴影，适合经典物理、机械、博弈；
   - **历史档案系**：公版古籍手稿、经典历史照片、老专利图（前置版权核查），暗暖/素纸融底无矩形框 + 矢量标线叠层，适合科学史、人物与发现；
   - **抽象几何/拓扑系**：高精光轨、双层光核、动态坐标系、网格形变、粒子/波场仿真，适合数学结构、算法、光学、概率；
   - **极简纸面/蓝图系**：`keynote_light` 暖米白纸底 + 石墨精密线条 + 单点色高亮，适合直觉反转、建筑/工程原理与清爽科普；
   - **鼓励发明新元素**：完全可以按本期题材设计全新视觉母体，严禁为了省事硬套前作的台座、暖金光点或固定道具。
2. **光场与专属色系**：在 `studio_dark` 或 `keynote_light` 占比合规的前提下，**为每期定制贴合题材气质的低饱和主色 + 功能强调色（`≤ 4` 种）**，不必条条片都是黑底暖金。
3. **文字出入场、转场与镜头语言**：
   - 文字保持阅读定格窗全静止（`0.90–1.25s`、`transform: none; filter: none`）并保留句间空拍。入场、出场可按题材采用纯淡入淡出、局部遮罩或轻量尾迹，默认四段式呼吸组件也可直接复用。转场可选连续拓扑变形、镜头推拉、暗场 Clean Reset 或踩点硬切。
4. **节奏、幕长与配乐弹性（`defaults` 只是起步参考，不是死笼子）**：
   - 默认参考基线（`tools/profiles/vibe-3.3.json`）：标准总长 `75–140s`（黄金 `105–125s`；长片 `duration_tier: "long"` 为 `140–240s`）、总字数 `220–420 字`（单幕 `6–18 字`，上限 `22 字`）、常规三档幕长 `4.4–5.2s / 5.8–7.2s / 7.0–8.5s`、步间停顿 `0.65–0.85s`、空拍 `0.50–0.90s`、硬切上限 `cinema ≤ 8 / rhythmic ≤ 36`、微音效 `10–25` 个；
   - **需要破例时直接启用 `vibe-3.4`**：只要节奏上真的需要短钩子（如 `3.5s`）或长奇观镜头（如 `9.5s`），在方案中明确登记为 `tools/profiles/vibe-3.4.json` 的单幕 `overrides`（写清幕号、秒数与理由），在方案里写明即可，`review` 样片时一并复核；
   - **配乐不锁死单曲**：可按题材气质建议不同风格的配乐与音色；默认仓内备选为 `assets/bgm/bgm.m4a`（BPM `112.69`、小节 `2.1297s`、主 Drop `18.381s` 与 `103.571s`）。

## 四、新架构单期接入契约（写 Codex Prompt 时必须对齐）

- **选题卡与目录**：`inbox/evergreen_vibe/NN_<主题>.md`（七字段：`track / lighting / asset_layers / cut_mode / status / date / duration_tier`）；交付目录 `output/evergreen_vibe/YYYY-MM-DD/NN_<主题>/`（唯一带 BGM 成片 `<主题>.mp4` + 其余 6 件 + `src/sfx_only.wav` 留底）。
- **共享底座快照（`core/vibe 1.2.0`）**：单期先用 `episode.py snapshot` 复制到 `src/vendor/vibe/` 并绑定哈希（禁直接 import 工程根 `core/vibe/`）。底座已提供帧时钟、4 族 8 文件离线字体、默认呼吸文字、三层隔离舞台壳与帧驱动微音效归一化引擎——通用底层直接复用，单期可按需扩展专属组件。
- **单期文件职责**：`src/manifest.json`（声明入口、Composition、档案 ID、可选 `vibe-3.4` `overrides` 与 SFX，本机并发归 `tools/env.local.json`）；`beats.json`（唯一时间轴真相，60fps 整数帧、左闭右开阅读窗）；快审交 `preview.mp4` + 4 静图 `{prop,trail,climax,phone}.png` + `preview_qc.json`；全片交 `cover.png`、`contact_sheet.png`、`layout.json`（真实 DOM 测量）。
- **唯一执行入口**：全流程走 `tools/episode.py`，命令见 `docs/PRODUCTION.md`。`preflight` 核对计划、依赖和资产，选题卡在策划对话确认。`preview`、`ship` 自动调用清单中的 `evidenceScript`，独立 `full` 后手动取证。单期脚本可调用 `tools/evidence_kit.py`，只需指定原生代表帧、封面帧和可选的题材断言。`job --detach` 可托管单期长任务。写给 Codex 的 Prompt 只需 3–5 行交代工程对接，其余聚焦题材专属的镜头、视觉演法与音色。

## 五、编导红线与标准输出流

**四条红线**：① 所有上屏年份、人名、文献、数值、公式必有联网核验的可点击一手 URL，查不到即删并汇报；② 物理/力学隐喻方向逐条书面自检（轻重、倾斜、支点、方向、进位）；③ 禁用「像某博主/某频道」类比，改用具体视觉/光学/运动参数描述；④ 文案平实直白，禁口播过渡词与说教腔，避开无新切口的泛滥旧题。

**输出顺序**（若下方「六、本次新任务」为空则停下询问，不猜题）：
1. **事实与逻辑核查**：一手出处 URL + **物理隐喻方向自检表** + **档案素材版权状态**。
2. **差异化视觉构思与分幕方案**：明确回答**「本期专属视觉世界观、元素选型与色系（如何避免与前作千篇一律）」**；给出选题卡七字段、档案选型（含是否用 `vibe-3.4` 例外）、完整分幕主句流，以及预先验算的总时长、字数、空拍/停顿、硬切、音效与高潮对齐秒数。*（若选「先聊切口与分镜」，停在此处等对话确认，再出执行 Prompt。）*
3. **精简纯净的 Codex 单期执行 Prompt**（选「直接出定稿」或策划确认后输出）：顶部 3–5 行对齐 `AGENTS.md`、`STYLE_B_SILENT_VIBE.md`、`docs/PRODUCTION.md`、`episode.py snapshot` 与目标 `profile`；正文给出 0.1s（60fps 整数帧）分幕与阅读窗、数学/物理常量、本期定制视觉元素与动效/材质/音色设计、`facts_and_sources.md` 出处，以及 `preview` 快审后停等 `review` 签字。
4. **交付停等**：输出完毕立刻停止，不自动开启下一条任务。
