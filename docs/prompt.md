# 单期新会话提示词

复制下面的提示词，并填写本期目录与任务。先读[协作流程](PROCESS.md)、[制作手册](PRODUCTION.md)和[视听规范](STYLE_B_SILENT_VIBE.md)。

```text
本期目录：<output/evergreen_vibe/YYYY-MM-DD/NN_主题>
本次任务：<策划、样片、全片、返工或只读复验>

只处理这一期。先读本期清单、分幕、事实文件和 status，确认当前卡点、
已批准的内容及未关闭意见。证据和批准以磁盘记录为准。

策划时核查一手出处与素材授权，交付分幕和事实文件。制作源码从
src/vendor/vibe/ 导入本期固定的 core/vibe 1.2.0；通过 evidence_kit
生成快审关键帧、手机缩略图及全片布局证据。

制作样片后停在 review。收到实际样片批准后，按制作手册登记 review，
运行 ship 完成全片、终混、取证、验收和归档。确认结果后将交付物送审，
收到实际终审采纳后登记 delivery。需要复验时使用 verify。
```
