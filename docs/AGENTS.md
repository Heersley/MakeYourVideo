# 单期制作约定

1. 先读[制作手册](PRODUCTION.md)和[视听规范](STYLE_B_SILENT_VIBE.md)，再从本期的 `beats.json`、`facts_and_sources.md` 和 `src/manifest.json` 接手。
2. 每次制作一条片。负责人在策划时确认题材、来源和分幕。上屏论断回溯到原始论文、官方文件、公版原著或其他一手出处。素材使用前确定授权，检查图形隐喻与原理的方向一致。
3. 源码从本期的 `src/vendor/vibe/` 导入公共原语。按本期绑定的制作档案生成样片，保留取证材料，由导演确认 `review` 后才能制作全片。
4. 完成混音、六项验收和归档后，由导演确认 `delivery`。按实际反馈登记签字和返工记录。
