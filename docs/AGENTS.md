# AGENTS.md — 竖屏无声科普片生产执行规范（v4.1）

> **本文件是唯一主指令**，优先级高于任何会话内的临时要求。
> **唯一轨道**：`evergreen_vibe` —— 0 人声 · 原生 2K 无声电影感科普。视觉、编码与验收细节由同级 `STYLE_B_SILENT_VIBE.md`（v3.3）接管，两者冲突时以 `STYLE_B` 为准。
> **裁决顺序**：`AGENTS.md` → `STYLE_B_SILENT_VIBE.md` → `PROCESS.md`（流程说明，不参与规范裁决）。
> **六条硬性规则**：① 事实核查先于一切提示词；② 人工卡点不可跳过；③ 严禁无人值守批量出片；④ 严禁在同一长会话中连续渲染多条全片；⑤ 1 个选题文件 = 1 条独立视频；⑥ 不清理他人的版本库历史（不执行 `git gc` / `git prune` / 强推）。

## 0. 一页速查

| 项 | 值 |
|---|---|
| 画幅 | `1440×2560`（9:16 2K）@ `60fps`，原生画布，禁 CSS 整体 `scale` |
| 编码 | `libx264 -profile:v high -level:v 5.1 -pix_fmt yuv420p -crf 16 -preset slow -g 120 -movflags +faststart` |
| 时长 | 标准 75–140s（黄金 105–125s）；长片 140–240s（须显式声明） |
| 文案 | 单幕 6–18 字（硬上限 22），全片 220–420 字 |
| 体积 | 2K 标准档约 18–65 MB（0.006–0.02 bpp） |
| 声音 | 0 人声；SFX 10–25 个（−16~−12 dB）+ BGM（−14~−18 LUFS）；禁 `-an` |
| 验收 | 6 项程序硬验收，全 PASS 才可交付 |
| 交付 | 唯一成片 `<主题>.mp4` + 6 件配套 |

## 1. 环境与工具链

### 1.1 必备

| 项 | 要求 | 校验 |
|---|---|---|
| Node.js | `^20.19` / `^22.13` / `>=24` | `node -v` |
| Remotion | `4.0.545` | `package.json` |
| Python | 3.11+，装 `requirements.txt` | `python -V` |
| FFmpeg / ffprobe | **≥7.0 且含 libx264**；Windows 需支持 `d3d11va` | `ffmpeg -version` |

> 缺失即停止并报告，不得自行降级编码参数或改用其它 codec。

### 1.2 工具优先复用

制作前先看 `tools/`。已有工具能满足需求时直接复用；参数差异优先用配置项解决；确需新增脚本时，同步更新 `README.md` 的工具表。

| 脚本 | 职责 |
|---|---|
| `tools/decoder_check.py` | 硬解验收闸门：D3D11VA vs 软解原生 NV12 对拍 + 纯灰连通域检测 + 编码档位审计（2K→`High@5.1`，1080p→`High@4.2`） |
| `tools/mix_bgm.py` | 交付终混：卡 Drop + 正偏移前段铺底 + 全片断层自检 + 唯一成片输出 + `sfx_only.wav` 导出 + 快审片时长裁剪 |
| `tools/bgm_analyze.py` / `bgm_common.py` | 测拍与节拍档案、PCM 解码、工具定位 |
| `tools/style_brief.py` | 从成片反推底色 / 色板 / 三段式占比 / 字阶 |

## 2. 目录与交付协议

### 2.1 目录

```text
.
├── docs/                     # 规范与流程
├── tools/                    # 公用脚本（保持洁净，不放一次性实验）
├── assets/
│   ├── fonts/                # 三套 OFL 字库（不入库）
│   └── bgm/                  # 自备配乐 + 生成的 *.beats.json（音频不入库）
├── examples/<name>/          # 可复现示例（纯源码）
├── topics/<slug>.md          # 选题卡（自建）
└── output/<slug>/            # 交付目录（不入库）
```

### 2.2 命名与隔离

- 交付目录 `output/<slug>/`，`<slug>` 与选题卡同名；日期写在选题卡里，不写进目录名。
- **1 个选题 = 1 条独立视频**；禁止多个选题拼一条、也禁止 1 个选题拆多条。
- 中间帧、分段渲染件、试编码件一律放本期 `output/<slug>/.work/`，验收通过后自动清理。

### 2.3 交付白名单（7 项，缺一不可）

| 文件 | 说明 |
|---|---|
| `<主题>.mp4` | 唯一成片：SFX + BGM 终混、`1440×2560@60`、`High@5.1`、AAC 256k |
| `bgm_mix_report.json` | BPM / 偏移 / 卡点误差 / LUFS / True Peak / 前段铺底 / 断层自检 |
| `beats.json` | 连续时间轴（分幕、气口、硬切、音效、duck 点） |
| `contact_sheet.png` | 逐幕联系表 |
| `cover.png` | 封面 |
| `facts_and_sources.md` | 一手 URL 闭环 |
| `src/` | 单期源码 + `final_qc.json` / `reading_qc.json` / `decoder_check.json` / `sfx_only.wav` |

**不产出**：双版成片、SRT、`captions.json`、`chapters.json`、口播音频、逐词字幕带、章节进度条。

### 2.4 选题卡必备字段

```yaml
---
track: "evergreen_vibe"
lighting: "studio_dark"          # 或 keynote_light
asset_layers: ["vector", "3d"]   # vector / 3d / 2.5d_parallax
cut_mode: "cinema"               # 或 rhythmic（须在 beats.json 同步标注）

```

缺字段即停止询问，不得自行假设 `lighting` 或 `duration_tier`。

## 4. 底层全局规则

### 4.1 规格与编码

- **`1440×2560` @ `60fps`**；H.264 **`High@5.1`** / `yuv420p` / `-movflags +faststart`。
- 逐字符遵守 `STYLE_B` §5.0：`-level:v 5.1 -crf 16 -preset slow -g 120`。
- **严禁** `slice-max-mbs`、`slices>1`、全 I 帧、阅读窗像素复制——它们会让 D3D11VA 解出纯灰块。
- `Level 5.1` 是硬约束：`1440×2560@60` = 14,400 宏块/帧、864,000 宏块/秒，4.2（522,240）与 5.0（589,824）都装不下。
- **2K 省盘**：全片流式直出，禁止整片 PNG 序列落盘；无损验收用定点抽帧（每幕阅读窗 3–4 帧 + 非硬切交界成对帧，全片约 120–180 张）。
- **严禁 `-an`**；混音/封装一律 `-c:v copy`，画面零二次编码。
- 体积自查：2K 标准档 18–65 MB；异常膨胀先怀疑编码 Hack。

### 4.2 画面纯净度

正片只保留：中部核心动态主画布、极简片名卡、低透明环境微动装饰。**禁止**水印、角标、免责/防御性标注、常驻日期/期数/学科标签、顶部进度条、底部字幕带、矩形外框套娃。核查过程留在后台，归档到 `facts_and_sources.md`。

### 4.3 事实核查（先于一切提示词）

- 每个上屏年份、研究者、文献、数值、公式都必须有**可点击的一手 URL**；一手直接用，二手明确标注；查不到就删掉并报告删了什么。
- 一手信源优先：官方博客 / 论文预印本（arXiv）/ 官方仓库 / 原始数据集；禁止二手聚合稿充当来源。
- **档案与手稿素材前置**：人物肖像、论文手稿、奖项证书、实物照片，须在阶段 1 完成来源与版权状态判定。
- **物理隐喻自检**：天平轻重、斜面倾斜、杠杆支点、卡爪开合、滚轮进位必须与命题方向一致。隐喻画反比画丑更致命。

### 4.4 人工卡点（四处，必须停等）

① 选题拍板；② 事实与数值定稿；③ `25–35s` 快审片验收；④ 逐条交付确认。任何一处未获确认，不得进入下一步，不得以「先跑起来再说」为由绕过。

### 4.5 单条隔离

1. **严禁同一个长会话连续渲染多条全片**。
2. 多条任务逐条在独立上下文执行；每条只加载：本规范 + `STYLE_B` + 该条选题卡 + 该条 `beats.json`。禁止携带其它条目的脚本、分镜、帧数据。
3. 每完成 1 条：写入 `output/<slug>/` → 输出当日进度（已完成 / 剩余 / 失败项与原因）→ 释放上下文再开下一条。
4. 任一失败项不得跳过或静默吞掉，状态保持非完成，列入汇总等待人工处置。

### 4.6 角色边界

| 角色 | 职责 | 不做什么 |
|---|---|---|
| 决策者（人） | 选题、口径、快审、交付四处拍板 | 不跳过卡点直接渲全片 |
| 编导 / 核查 | 一手核查、隐喻自检、分幕与气口、给编码代理写指令 | 不编造事实、不写动画代码 |
| 成片工程 | 源码、两阶段渲染、跑验收、混音、清理 `.work/` | 不改叙事、不擅自改规范 |
| 基建维护 | 规范文档、`tools/`、目录与磁盘 | 不碰正式成片、不动他人历史 |

> 角色可由任意等效工具承担；关键是**四种职责不合并到同一个会话**。

### 4.7 发布与合规

- 发布时按平台要求勾选 **AI 生成内容声明**，保留导出文件的元数据。
- BGM 只用 CC0 / 已获商用授权曲目；商单替换配乐时用 `sfx_only.wav` 重混，不重渲画面。
- 不复用他人台标、肖像、声音；字体须为可商用授权（本仓库推荐三套 OFL）。
- 同一提示词批量产出叙事高度近似的视频，属于低质矩阵内容——不做。

## 5. 分阶段触发语

> 每条末尾必须停止并等待人工确认，不得自动连跑。

**阶段 1 · 核查与分幕定稿（不写动画代码）**

```text
读取 docs/AGENTS.md 与 docs/STYLE_B_SILENT_VIBE.md。基于 topics/<slug>.md 执行，不写任何动画代码。
① 一手事实核查：论证链每个年份、研究者、文献、上屏数值与公式都给可点击 URL；
   查不到出处的条目删除并报告删了什么；档案/手稿素材同步完成版权判定。
② 物理/力学隐喻自检：逐条核对方向与命题是否一致。
③ 变量表：片名 / 一句话命题 / 答案 / 论证链 / 主视觉母题 / lighting / asset_layers / 边界声明。
④ 分幕：主句 6–18 字（硬上限 22）、单幕时长按复杂度分层（4.4–5.2 / 5.8–7.2 / 7.0–8.5）、
   句间空拍 0.50–0.90s、步间停顿 0.65–0.85s、反转前 0.35–0.50s、
   硬切清单、微音效表，Σ durationSec ∈ [75,140]（长片 [140,240]）。
输出：核查清单 + 隐喻自检 + 变量表 + 分幕表 + 音效表。到此停止。
```

**阶段 2 · 快审片（强制停等）**

```text
只渲染前 25–35 秒：720×1280 @ 30fps，用 tools/mix_bgm.py --preview-duration 直接带 BGM+SFX 出片。
附 seam_delta 逐幕读数、静态文字包围盒抽样、2K 关键帧静图（道具特写 / 尾迹中段 / 高潮结构）
与一张 360px 逻辑宽的「手机实看缩略模拟图」。到此停止，未点头不得渲染全片。
```

**阶段 3 · 全片与 6 项验收**

```text
流式渲染 1440×2560 @ 60fps 全片（帧不落盘）：
① 严格按 STYLE_B §5.0 编码；严禁 slice-max-mbs、全 I 帧、slices=NN、阅读窗像素复制。
② 定点抽帧跑 text_box_diff === 0.000 与 seam_delta。
③ tools/mix_bgm.py 出唯一成品 <主题>.mp4 + src/sfx_only.wav + bgm_mix_report.json；
   确认 bgm_gap_check.pass = true、climax_error_sec ≤ 0.03。
④ 6 项硬验收；第 6 项 tools/decoder_check.py --strict 对唯一成品跑 1 次，PASS 后落盘 src/decoder_check.json。
⑤ 成品与报告全部落在 .work/ 之外且可读后，自动清理本期 .work/。
未通过项如实报告并修复复验，不得宣称完成。输出后停止。
```

## 6. 发布前 Checklist

1. **编码**：`ffprobe` 实测 `1440×2560` / `60fps` / `High@5.1` / `yuv420p`；`decoder_check.py --strict` PASS。
2. **声音**：非 `-an`；`sfx_only.wav` 峰值 −16~−12 dB；终混真峰值 ≤ −1.0 dBTP、集成 −14~−18 LUFS；`bgm_gap_check.pass = true`。
3. **画面**：无禁用元素；联系表逐幕目视通过；L3 线宽 ≥2.5px、暗场标注亮度 ≥`#CFC7B8`。
4. **事实**：`facts_and_sources.md` 覆盖全部上屏数值、公式与素材来源，URL 可点开。
5. **许可**：BGM / 字体 / 素材授权齐全；AIGC 声明已勾选。
6. **交付**：7 项白名单齐全，`.work/` 已清空。
