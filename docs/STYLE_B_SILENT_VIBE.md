# STYLE_B_SILENT_VIBE.md — v3.3 视听规范

原生画布、零人声、持续演化的视觉推理、克制的微音效与配乐是本轨道的表达方式。文字与可读标注在定型时锁定整数像素。导演在策划对话中核实天平、杠杆、斜面等隐喻的方向和因果，以及档案素材出处与许可；样片 `review` 时复核成片是否守住这些结论。

## 一、规则归属

| 规则 | 判断依据 |
|---|---|
| Hard | 本期 [制作档案](../tools/profiles/) 的 `hard` 管画幅、编码、声音、光场、安全区、ROI、分幕边界与硬解。六项验收还包含 DOM 框、无损 PNG、事实出处和导演目视证据。 |
| Default | 单幕常规时长由 `defaults.beatDurationSec` 给出。显式采用 vibe-3.4 时，具体幕号与秒数写进清单 `overrides`，随样片 `review` 一并确认。 |
| 视觉制作规范 | 下文的字阶、字距、尾迹、线宽和光效由 Render 执行，结合高分辨率关键帧与手机缩略图核查。 |
| Creative | 每期选择视觉母题、道具、空间隐喻、材质和镜头设计，由导演审片。 |

## 二、运动与节奏：9 条运动学与零死帧规则

1. **对象恒常性与连续拓扑变形（Object Permanence & Morphing）**：
   - 画面核心实体**严禁无缘由整体销毁后再凭空弹窗**；
   - 信息推进必须通过同一实体的连续形态演化完成（点拉成线、线折为坐标、二维图形立起为三维曲面、符号拆项滑入新位、散点聚合为边界），确保观众视线始终被一只无形的手平滑牵引。
2. **电影级长尾非对称缓动（Asymmetric Cinema Easing）**：
   - 严禁显眼前景物体使用生硬线性匀速，严禁廉价玩具式 Q 弹回弹（`spring` 一律 `overshootClamping: true`）；
   - 核心演化统一采用**「利落起势 + 极长羽毛般减速尾韵」**曲线（等效 `cubic-bezier(0.16, 1, 0.3, 1)` 或指数/五次方 `ease-out`，最后 25% 的细微位移占去过半时间，落位如磁吸般零撞击感）；长镜头推拉使用平滑 S 曲线（`cubic-bezier(0.65, 0, 0.35, 1)`）。
3. **交响式微错峰与动作重叠（Micro-Stagger & Overlap）**：
   - 同一幕内严禁所有元素在同一帧齐刷刷生硬入画或同时刹停；
   - 按视觉主次错开 **`60ms–140ms`**（主体起势 → 辅助线/刻度跟进 → 主句合焦 → 读数显现），相邻动效保留 **`20%–30%`** 时间重叠。若采用逐字尾迹，默认字间错峰 `28–35ms`。
4. **连续虚拟摄影机与 Z 轴视差（Virtual Camera Continuity）**：
   - 将竖屏视为望向三维/无限空间的摄影机取景框，全片贯穿极微弱且连贯的镜头运动（整幕缓推 `scale 1.00→1.04`、优雅跟焦平移、前/中/远三层 Z 轴视差）；
   - 场景转换优先靠主体变形与镜头穿越完成，全片硬切严格克制（次数见 `hard.timeline.maxCuts`，rhythmic 须卡节拍）；
   - **文字例外**：顶部主句大字与底部等宽读数**永久移出**任何摄影机 `scale` / 漂移容器，不随镜头运动，详见 §3.2。
5. **零死帧与思考停留窗规则（Zero Dead-Frame & Thinking-Window Rule）**：
   - **「电影留白」指暂缓抛出新文字，绝不是画面冻住不动**；
   - 死帧取中层主舞台 ROI，采样、片尾豁免及静止判据见档案 `hard.visual`。全屏结果用于交叉参考。
     - **依然严禁**为刷帧差给静止文字加微晃、给背景加大旋转尘盘或短周期扫光（见 §4.2、§2.9）。
   - 核心图形演化必须借助长尾曲线铺满单幕**主动演化阶段**的 **`80%–95%`** 时长，即使主体趋近定格，摄影机缓推、背景微尘粒子、光晕呼吸或三维线框自转也绝不刹停；
   - **复杂度分层 + 思考停留窗（2K 版重标定）**：
     - 推导步骤之间稳停 **`0.65–0.85 秒`**（2K 信息密度更高，较 v3.2 的 `0.5–0.6s` 放宽，让眼睛有时间扫完读数）；
     - 每幕演完定型后，稳稳停留 **`0.8–1.2 秒` 思考消化窗**（此时主句文字与公式 **100% 纹丝不动**，仅纯几何线框 / 背景微光维持呼吸感）；
     - **关键反转前预留 `0.35–0.50 秒` 蓄力停顿**（画面只留呼吸感，不出新元素），让反转有「吸气—落锤」的重量；
     - 单幕按过场、推导、奇观选择 `defaults.beatDurationSec` 三档。奇观幕须有连续递进动作；总长按 `hard.timeline.duration` 校验。
   - **幕间干净接力**：非硬切幕按 §2.7 干净过渡哲学衔接（旧辅助元素先 `0.40s` 淡出清空，再滑入新结构），不再用提前起势去挤压思考消化窗。
6. **同源物理声画咬合**：涉及节奏、步进、计数或频率的片段，视觉加速度、光强脉动与物理音效须由同一时间函数同源驱动，达到毫秒级同步。
7. **持久舞台状态机与干净过渡哲学（Persistent State Machine & Clean Transition）**：
   - **单一持久状态机**：连续大幕必须由**全局 `frame` 驱动的单一持久舞台状态机**渲染，上一幕末帧实体的坐标 / 缩放 / 透明度与下一幕首帧**严格相等（`===`）**，严禁每幕独立组件重置导致画面跳回重播；交界处须跑 `seam_delta` 无重置尖峰自检（见 第五节），判据为 `seam_delta ≤ 0.01`、`max_pixel_delta ≤ 2`、变动像素占比 `≤ 0.01%` 三条同时成立，仅放行并发 worker 的 1–2 级极微抗锯齿噪声，元素跳动或边框残留仍当场失败；
   - **区分「同系变形 Morph」与「异构换场 Clean Reset」**：
     - **Morph（同系变形）**：同一拓扑家族的连续演化（点→线→坐标、正方形→立方体、公式拆项滑入新位），必须保持实体连续、禁销毁重弹；
     - **Clean Reset（异构换场）**：拓扑完全不同的结构切换（如「天平」换成「二进制竖式」、「卡爪抓取」换成「坐标网格」）**严禁强留残缺旧边框做伪连续压叠**——那会留下半截旧线框与新结构互相穿帮。必须按**四拍换场**执行：
       1. **旧结构退净 `0.40s`**（整体降对比 + 轻微散焦后淡出，不留残余边框）；
       2. **纯暗呼吸空拍 `0.20–0.30s`**（只留底光与微尘，给眼睛一次「眨眼」）；
       3. **新主体先成型 `0.45–0.65s`**（几何骨架先立住，此间**不出文字**）；
       4. **上层主句浮现 → 底部读数滞后 `0.20–0.30s` 淡入**（读数永远后到，不与新结构抢第一眼）。
   - **背景不抢戏**：背景微尘保持极暗极淡（`opacity ≤ 0.08`），**严禁放旋转大尘盘或花哨背景动画抢戏 / 刷零死帧**；镜头呼吸感只交给纯几何线框、粒子与光晕；
   - **主舞台真实演规则**：核心数学 / 算法规则与关键符号必须搬到中层主舞台**大尺寸演明白**，严禁藏在底部小字里、中层只放装饰性几何体；
   - **干净过渡**：禁止把不同拓扑的符号强扭成怪异折断线；旧辅助元素先 **`0.40s` 干脆淡出清空**再滑入新结构；优先纤细通透线框，避开厚重不透明实心色块与冗余 3D 尾巴；**全片统一规范下标**（字号 / 基线 / 字距 / 颜色一致）。
8. **具象交互的四段物理曲线（抓取 / 叠放 / 滚轮）**：
   - **抓取器造型**：双侧通透悬浮卡爪，替代笨重闭合大方框；卡爪只做轻微收拢，不做夸张机械开合；
   - **四段动作**：① 预备收拢 + 离台微浮（投影随离台高度拉散）→ ② 三次贝塞尔弧线滑移（带轻量残影，**禁止直线平移**）→ ③ 严格统一空间归属方向（如先手统一向上、后手统一向下，**严禁中途反向穿帮**）→ ④ 关联数字垂直滚轮滑切；
   - 四段按 §2.3 微错峰保留 `20%–30%` 重叠衔接，不得逐段硬切。
9. **环境光效速度与亮度硬上限（v3.3 新增，根治「倍速扫光」）**：
   - **台座 / 边框镜面流光**：单程扫掠周期 **`≥ 8–12 秒`**，2K 线速度 **`≤ 95 px/s`**；**单向慢掠后消隐**，严禁短周期来回往返扫（往返扫是最典型的「廉价倍速感」，也最容易被误用来刷帧差）；
   - **光带形态**：带宽拉宽至 **`260–360 px`** 柔羽化（高斯/指数双段衰减），峰值不透明度 **`≤ 0.20`**；
   - **边缘 / 光晕呼吸**：周期 **`6–9 秒`**，幅度 **`±6%–10%`**（相对基准亮度），禁止 `1–2s` 级快闪；
   - **互斥原则**：当主体自身已有主动微动（2.5D 旋转 / 推进 / 材质高光巡游）时，底座**禁止叠加额外扫光点**——一处主动、一处被动，绝不双开；
   - 以上参数是**上限**不是目标值；同一幕内只允许 **1 处**慢速光效在动。

## 三、视觉与排版：10 条光学、材质、排版、字体与线宽规则

1. **双光学舞台（`lighting`，单条内保持统一光场，仅重大概念反转时可平滑转场）**：
   - **`studio_dark`（暗场摄影棚光学 · 默认）**：
     - 底色固定深邃极暗空间（`#050608–#0B0A09`，默认 `#060709`），全片光场按 `hard.visual.lighting` 实测；
     - 主字暖米白 `#F2EDE4`、核心亮线暖金 `#C9A96A`、次级读数冷灰 `#5C6370`；按概念区分维度需要可启用 **`≤ 4` 种低饱和功能编码色**（每色必绑定明确语义）；
     - 叠加极克制的**定向柔光衰减（Volumetric Falloff）**、纤细边缘高光（Rim Light）与 Z 轴极微漂浮微尘，营造真实暗室摄影棚纵深。
   - **`keynote_light`（苹果发布会级洁净展台光学）**：
     - 严禁刺眼纯白 `#FFFFFF` 与生硬纯黑 `#000000`；底色锁定温润陶瓷白/微暖纸灰（`#F4F2ED–#ECE9E2`，默认 `#F2F0EB`），全片光场按 `hard.visual.lighting` 实测；
     - 主字石墨深灰 `#1C1C1E`、次级文字 `#6E6E73`、克制高级功能强调色（≤ 4 色）；
     - 主体配极柔和的多层**环境遮蔽软投影（Soft Ambient Occlusion）**与细腻表面反光，呈现工业设计展台般的秩序与高级感。
2. **光学景深与静态文字零颤动要求（DoF & Zero-Jitter Static Text）**：
   - 画面严格区分**前景微尘 / 焦点主角 / 远景空间**三层景深，同屏永远只有 **1 个视觉焦点**；退居次要地位的图形不粗暴抹除，而是通过**平滑降对比度 + 轻微光学散焦（`blur: 0→5px`）+ 微缩退后**自然让位；**光学散焦 `blur` 仅允许作用于退居背景的非文字图形，严禁作用于前景可读文字**；
   - **静态文字零颤动**：
      - 顶部主句大字与底部等宽读数**永久移出**任何摄影机 `scale` / 漂移容器。阅读定型保持 `transform: none; filter: none; opacity: 1` 和整数像素坐标；默认入场为纯透明度渐变。
     - **文字四段式呼吸生命周期（v3.3 核心，替代 v3.2 三段式；唯首幕第 0 帧直接满显入戏例外）**：
       1. **幕首留白气口**：`beatStart` 之后先留 **`0.35–0.55 秒`** 空镜/纯图形气口再起主句；**大章节/大结构转折处放宽至 `0.60–0.85 秒`**。这一段只允许图形骨架与底光呼吸，**不许出任何新文字**——它解决的是「上一句刚飞走、下一句立刻顶上来」的窒息感；
       2. **[Default / 可选默认实现] 从容入场**：**`0.38–0.45 秒`** 纯 `opacity 0→1`，固定整数像素。单期可采用克制的局部遮罩等方式，进入阅读窗前完成。
       3. **阅读定格窗**：按 `hard.timeline.readingSec` 保持 100% 全静态（`transform: none; filter: none; opacity: 1` + 整数像素）。这是 `text_box_diff` 的**唯一检测区间**，必须 **`=== 0.000`**；
       4. **[Default / 可选默认实现] 右上尾迹**：出场可用 **`0.60–0.72 秒`**，字间错峰 **`28–35ms`**、行间约 `60ms`，最右字先向右上 `28°` 启程。2K 位移 **`dx +214px / dy -114px`**，`easeInQuad` 起步，前 `35%` 维持 `0.88–1.0` 可见度。单期可选其他出场，均须在 `beatEnd - 0.15 秒` 前归零。
       5. **[Default / 可选默认实现] 五层残影**：采用尾迹时可沿反方向叠五层定向模糊，峰值为 `0.46 / 0.30 / 0.18 / 0.09 / 0.04`，用独立时间包络，避免与主字透明度相乘。静态阅读窗保持 `0.000` 像素差。
     - **全片节奏校验**：任意相邻两句的「上一句归零 → 下一句起句」必须 ≥ `0.50s`（对应「幕尾余白 `0.15s` + 幕首气口 `0.35s`」的下限组合）；同一幕内两句间隔上限 `0.90s`，超过即视为拖沓，需合并或删句；
     - 中层舞台中的数字、箭头、符号、层标**严禁**挂摄影机微推或 `sin(frame)` 漂浮（微推 / 呼吸感仅给纯几何线框、粒子、光晕）；仅在明确的主动位移 / 展开窗内丝滑运动，**一到定型态立刻 `clamp` 锁定整数像素、`scale(1)`、`filter: none`**；
     - 动态滚动数字强制 `font-variant-numeric: tabular-nums` 且采用**固定绝对定位**（如等号从滚动第 1 帧即固定左侧，禁突现导致整行横跳）；
     - 验收口径：**仅阅读定格窗**内静态文字包围盒像素差 `=== 0.000`（`text_box_diff`，见 第五节）；入场段、气口段与出场段不参与该断言，但出场必须满足第 4 条的「`beatEnd - 0.15s` 归零」；
   - **高亮风格前后统一**：全片主句高亮词按剧本**每幕统一 1 处变色高亮**，严禁前半段无高亮、后半段突现。
3. **2K 苹果发布会级大留白排版与安全区**：
   - **平台 UI 避让安全区**：见本期档案 `hard.visual.safeZone`；所有元素（含引线端点、粒子尾迹、投影外扩）不得越界。
   - **三段式呼吸构图**：
     - **上层叙事区 `y: 306–694`**：当前幕唯一主句，**双层主次排版** —— 核心主行 `Bold 700` 按单行字数自适应 **`104px（≤7 字）/ 98px（8–9 字）/ 90px（≥10 字）`**、色 `#F5F1E8`，关键词暖金 `#E2C17A`；铺垫辅行 `Regular 400` **`76px`**、色 `#CCC6BB`；CSS 字族栈统一写 **`"Source Serif 4", "ChillJinshuSong", serif`**；宽字距 `0.06em–0.10em`，行高 `1.45`，单行 ≤ 12 字、最多 2 行，每句最多 1 处高亮变色，无描边无底框；**禁止两行同字号同字重平铺**；开场悬念、高潮转折与结尾余韵允许**全屏居中（`y: 1040–1360`）**独显；
     - **中西混排微距**：中文与西文/数字交界、数字与单位交界处统一插入 **`0.15em`** 视觉微间距（用 `&thinsp;` 或分段 `margin-right: 0.15em` 实现，**不得用全角空格**），确保 `(1, 2, 3)`、`1440×2560`、`O(√n)` 这类混排在 2K 下不糊成一团；
     - **中层演化主舞台 `hard.visual.roiY`**：与上下文字留白 **`≥ 106px`**，严禁字压图；承载逻辑的**中层标注**用 `Noto Sans SC` **Medium `≥ 44–48px`**、亮度 **`≥ #CFC7B8`**（不许用 `#5C6370` 这类次级灰写承担因果的字）；标签须置于纯暗留白净空区并配短引线，严禁压在透视台座斜边框线上；
     - **下层微读数区 `y: 1880–1980`**（非常驻）：`JetBrains Mono` **`40–42px`**、`tabular-nums`、低对比度；括号紧贴数字写 `(1, 2, 3)`，不写 `( 1, 2, 3 )`；
   - **滚轮数字裁剪与标签避让**：垂直滚轮切换的变动数字位必须套紧贴行高的 `height: 1.15em; overflow: hidden` 裁剪框，防止滚动瞬间旧数字探出行外；
   - **零界面杂音**：无顶部进度条、无底部 28% 逐词字幕带、无右上角常驻小装饰、无矩形外框套娃、无 2.5s 片头纯标题卡、无角标水印。
4. **分层混合视觉资产管线（`asset_layers`）**：
   - Remotion @ 60fps 代码是绝对的运动学、摄影机与排版骨架，按题材自由组合三类高质感视觉层：
     - **`vector`**：可连续拓扑变形的数学级矢量曲线、点阵、坐标、公式重组；
     - **`3d`**：`@remotion/three` 或预渲染序列构成的受光 3D 几何与真实材质（磨砂玻璃、哑光金属、受光曲面、高维线框）；
     - **`2.5d_parallax`**：电影级分层光影底景（拆为远景氛围光、中景主体、前景体积光/微尘三层，由代码驱动 Z 轴视差缓推与统一色温调色，须带固定种子与资产清单，严禁廉价静态生图硬切拼贴）。
5. **叙事文案与克制声学空间**：
   - **第 0 帧即入戏**：禁止黑屏淡入；第 0 帧直接呈现第一幕悬念大字（≤ 14 字，提问/填空/反差）与流动视觉锚点，第 `3.0–4.5s` 给出第二拍转折；
   - **文案精炼度**：单幕主句 **`6–18 字`（硬上限 22 字）**，全片标准档主文案 **`220–420 字`**；禁用一切口播过渡词与说教腔；结尾必须回扣开头并配极简电影片名卡缓隐落幕，严禁求点赞关注；
   - **物理共鸣微音效（严禁 `-an`）**：仅用真实物理共鸣音色（五声泛音钟、深沉平滑低频脉冲、细微材质摩擦，或与算法/频谱同源绑定的清脆乐音步进；严禁 `whoosh/pop/滑稽音效`），母带峰值按 `hard.audio.sfxPeak`；常规片微音效数量按 `hard.timeline.cinemaCues`（节律映射题材可随事件触发）；
   - **后期配乐**：默认单曲 `assets/bgm/bgm.m4a` 由 `tools/mix_bgm.py` 卡 Drop 混入（`-13.5dB` 基准，响度见 `hard.audio.lufs`），于最高潮反转前留 `0.4–0.6s` 柔和动态洼谷；铺底检测区间与断层上限见 `hard.audio`。
6. **前景主角双层光学亮核（Dual-Layer Optical Core）**：前景主角光点采用**双层光学亮核** —— 亮暖白金实核 `#FFF6DF–#F0D594` + 柔和低透明暖金外晕（`opacity 0.22–0.32`）；严禁单层粗重高饱和外发光（见 §4.3），实核尺寸与外晕衰减全片统一。
7. **留白与图层丰富度（宏观极简、微观精工）**：
   - 单屏单一视觉焦点与大留白构图不变；**拒绝廉价元素堆砌，也拒绝空洞简陋的线框**——高级感来自核心主体的材质、光影与细节刻画；
   - **精选图片 / 历史档案图层（按需、克制）**：涉及历史人物、经典手稿、权威奖项、具象实物概念时，允许在纯矢量体系外引入高品质图片图层（人物肖像、公版论文手稿、宏观概念特写），**每片只选少数关键锚点**，避免万物强行手画矢量；**此类素材必须在快审 就完成版权与来源前置核查**（见 操作手册），不得等画到一半才发现不能用；
   - **图片融底三要点**：① 统一暗暖低饱和影调（暗部贴近 `#060709`，亮部偏暖米白/暖金）；② 四周柔和径向羽化自然融入底色，**禁止生硬矩形边框**；③ 配合极缓 2.5D 镜头微推，并在图层之上叠加精密矢量标线、高亮框或公式标注。
8. **具象道具的精工渲染（避开粗糙低模 SVG）**：
   - **禁用**：简单扁平 SVG 多边形 + 均等线框硬凑；在实体道具正中央强行叠加发光小白点（**双层光核 §3.6 只适用于抽象节点 / 光点**）；
   - **推荐做法**：本地程序化 3D 高度场 / 法线解析 + GGX 物理高光超采样离屏渲染透明 PNG 精灵（`numpy` + `PIL`，固定种子确定性生成，**按 2K 显示尺寸 `2×` 超采样**，含 3–4 颗微妙偏航 / 肌理变体消除复制粘贴感），再叠加矢量动态轮廓高光层；
   - **物理立体感四件套**：
     1. **冷暖材质分离**：主体与承托台座拉开冷暖 / 明暗层次（如冷石墨黑曜石 + `45°` 拉丝暖金高光倒角棱，置于深墨暗铜台座之上），杜绝「暗色糊在暗色上」；
     2. **双层真实接触投影（Contact AO）**：紧贴物体底缘的高浓暗核闭塞影 + 外扩柔阴影；叠放时上层物件须真实投影在下层顶面，物体被提离时投影随离台高度扩散衰减；
     3. **克制桌面微倒影**：抛光暗台面上的底层物件可加极淡垂直衰减倒影（顶部 `opacity ≤ 0.14` 迅速渐隐），增强真实落座感；
     4. **优雅防静止活性**：用台座边框镜面流光巡游、受光倒角棱轻呼吸等**非文字区纯光学微动**提供真实活性，参数严格受 §2.9 上限约束；**严禁**用槽轨穿梭小白点、文字微晃或花哨背景凑帧差（见 §4.2）。
9. **字体选型与主次层级（四个开源字族、三层排版，防丑字体与小气感）**：
   - **字库归档与加载**：四个字族的八个静态字体文件统一归档 `assets/fonts/`，随片经 `@font-face` + 本地静态文件离线加载（不走 CDN、不依赖系统预装）；三层各司其职，**不跨层混用**；
   - **① 上层旁白大字（叙事主句）**：中文 **寒蝉锦书宋 V2.0**（`ChillJinshuSong`，`Regular 400` + `Bold 700`，源 `github.com/Warren2060/ChillJinshuSong`）＋ 西文 / 数字 **`Source Serif 4`**；栈统一 `"Source Serif 4", "ChillJinshuSong", serif`；
   - **② 盘面与界面小标注**：默认使用开源无衬线 **`Noto Sans SC`**（Regular 400 / Medium 500）；单期选用 `Source Han Sans SC` 时须显式加载本地文件；
   - **③ 公式与等宽读数**：**`JetBrains Mono`** ＋ `font-variant-numeric: tabular-nums`；含中文的公式说明回落 ②；栈 `"JetBrains Mono", "Noto Sans SC", monospace`；
   - **授权与禁用**：四个字族均为 SIL OFL 1.1（以各仓库 `LICENSE` 为准），可免费商用；**不绑定任何手机厂商字体**，手机厂商定制字库一律不进入本工程；
   - **快审须报备**：`document.fonts` 实测生效的字体名称与字重文件；**严禁使用或静默回退至 `Microsoft YaHei` / `STZhongsong`（华文中宋）/ `SimHei` / `SimSun`**；
   - **主次反差**：按 §3.3 双层主次排版执行（主行 `104 / 98 / 90px` 用 ① 的 `Bold 700`，辅行 `76px` 用 ① 的 `Regular 400`）；盘面标注用 ②（`≥44–48px` Medium），公式与下层读数用 ③（`40–42px`）；
   - 全部文本在定格态仍须通过 `bounds.py` 严守 `x: 120–1212, y: 240–2000`。
10. **2K 手机可见性线宽硬分级（v3.3 新增，根治「过细过暗」）**：
   - **判据前提**：成片在 6.1 英寸手机上等效观看宽度约 360 CSS px，即 2K 画面按 **1:4 缩小**。因此 `1–1.5px` 的线在手机上是 `0.25–0.38px`，必然消失或抖成虚线。所有承载信息的线必须按下列分级落地（数值为 2K 画布实际像素）：
     - **L1 核心主结构与关键特效**（主梁、配对弧、断裂高亮、核心箭头、光轨）：**`4.5–8.0 px`**；可配 **`16–26px` / `opacity 0.16–0.24`** 柔暖光衬底（衬底不计入线宽，但不得把线糊粗）；
     - **L2 交互控件与示意骨架**（抓取卡爪主体 `4.0–5.0px` / 拐角加强 `6.0–7.0px`、坐标轴、示意图轮廓、柱条边框）：**`3.5–4.5 px`**；
     - **L3 辅助标尺 / 虚线 / 引线**：**硬下限 `≥ 2.5 px`**（**严禁 `1–1.5px` 细线**），不透明度 **`≥ 0.38`**；承载因果含义的次级连线（如「因为→所以」的指向线）**`≥ 0.52`**；
     - **粒子与速度丝**：粒子直径 **`7–12 px`**、尾迹速度丝 **`3.5–5.5 px`**；PBR 精灵按 2K 显示尺寸 `2×` 超采样生成（见 §3.8）；
   - **暗场补偿**：`studio_dark` 下颜色亮度本身偏低，L2/L3 线宽必须配合「提亮 `+8%–12%`」使用，禁止只加粗不提亮（加粗不提亮会变成一坨灰）；
   - **验收**：快审 的 360px 逻辑宽手机缩略模拟图（操作手册）里，L1/L2 线必须**连续可辨**、L3 线必须**不消失**；看不清即回炉，不许等到 2K 全片才发现。

## 四、6 条质量红线

1. **禁 PPT 翻页**：禁止无拓扑延续关系的整屏淡出再弹窗（同系必须 Morph；异构必须走 §2.7 四拍 Clean Reset，不得硬切压叠）。
2. **禁死帧**：中层舞台按 `hard.visual` 实测，阅读窗文字须静止，背景微晃不能充当主体演化。
3. **禁塑料霓虹发光**：禁止高饱和单层粗重外发光，发光必须低透明多层指数柔衰减（前景光点按 §3.6 双层亮核实现）。
4. **禁默认裸字**：禁止不调字距、行高、字重反差的粗糙排版；文字必须遵守 §3.2 四段式生命周期与零颤动要求。
5. **禁信息过载**：单屏永远只服务 1 个核心念头，解释性废话一律删掉改用图形演出来。
6. **禁画风拼贴**：引入 3D/2.5D 资产时，黑场/白场基底、光影方向与色温必须与代码层 100% 统一。

## 五、六项验收与目视证据

1. 规格与音轨。核对最终码流、混音前后同流、响度、真峰值、拍点和铺底明细。
2. 光场。按本期 lighting 检查逐帧光场统计。
3. 分幕与运动。按真实阅读窗取原始 PNG 核验静态文字和非硬切接缝，解码成片检查 ROI 静止时长。文字零差以无损帧为准。
4. 版式。核对 DOM 框、逐幕联系表和手机缩略图，导演目视判断避让、线宽、对比度和纯净度。
5. 事实。核对所有上屏数值、公式、人物、档案素材及其一手来源。
6. 硬解。对唯一成片做严格 D3D11VA 与软件 NV12 对拍，核对全片切片覆盖、异常灰块及编码告警。

preview 须同时交带声快审、道具特写、尾迹中段、高潮结构和手机缩略图。review 获批后才进入 full。正式制作使用流式编码与定点抽样，禁止全片 PNG 落盘、阅读窗像素复制、微分片和全 I 帧。执行、证据与归档按 [单片操作手册](PRODUCTION.md)。
