## 一、画幅、时长与声音基线

1. **规格**：**`1440×2560`（9:16 2K）@ `60fps`**。
   - **原生 2K 画布**：构图、字号、线宽、坐标按 1440×2560 直接设计；**严禁**先按 1080×1920 排版再用 CSS 整体 `transform: scale(1.333)` 放大——整体缩放会让文字落到非整数像素并引发 Chromium 字体重采样颤动。
   - **静态元素锁整数像素**：主句、读数、中层可读标注的 `left/top` 与 `font-size` 一律整数 px；定型态 `transform: none; filter: none;`。
   - 输出 `yuv420p`（4:2:0 下 2K 色度为 720×1280，暖金细线与暖米白字的过渡须靠 §3.10 线宽下限保障）。
2. **时长**：
   - **标准档（默认）**：`75–140 秒`，黄金体感 `105–125 秒`。
   - **长片档（特批）**：选题卡显式声明 `duration_tier: "long"` 时放宽至 `140–240 秒`。
3. **唯一 0 人声驱动**：全片不出现人声，不生成 SRT，不设底部逐词字幕带。只由 **`beats.json` 连续时间轴 + 极精炼大字 + 视觉自解释演化 + 克制物理微音效 + 后期配乐**驱动。
4. **唯一成品**：只交付一条自带 SFX + BGM 终混的 `<主题>.mp4`（详见 §5）。干净微音效轨只作为渲染中间物与 `src/sfx_only.wav` 母带留底，**不交付双版**。

## 二、运动与节奏：9 条运动学与零死帧规则

1. **对象恒常性与连续拓扑变形**：
   - 核心实体**严禁无缘由销毁后再凭空弹窗**；
   - 信息推进必须通过同一实体的连续形态演化完成（点拉成线、线折为坐标、二维立起为三维、符号拆项滑入新位、散点聚合为边界）。
2. **电影级长尾非对称缓动**：
   - 严禁显眼前景物体线性匀速，严禁玩具式 Q 弹回弹（`spring` 一律 `overshootClamping: true`）；
   - 核心演化用「利落起势 + 极长羽毛般减速尾韵」（等效 `cubic-bezier(0.16, 1, 0.3, 1)`，最后 25% 的位移占去过半时间，落位零撞击）；长镜头推拉用 `cubic-bezier(0.65, 0, 0.35, 1)`。
3. **交响式微错峰与动作重叠**：
   - 同一幕内禁止所有元素同帧齐出或同时刹停；
   - 按主次错开 **`60–140ms`**（主体 → 辅助线/刻度 → 主句合焦 → 微读数），相邻动效保留 **`20%–30%`** 重叠；文字内部逐字错峰另按 §3.2 的 `28–35ms`。
4. **连续虚拟摄影机与 Z 轴视差**：
   - 整幕缓推 `scale 1.00→1.04`、优雅跟焦平移、前/中/远三层视差；
   - 场景转换优先靠主体变形与镜头穿越；硬切严格克制（常规 `≤8` 次；`cut_mode: "rhythmic"` 且卡节拍时可放宽至 `≤36` 次）；
   - **文字例外**：顶部主句与底部读数永久移出任何 `scale`/漂移容器。
5. **零死帧与思考停留窗**：
   - **「留白」指暂缓抛出新文字，绝不是画面冻住**。
   - **检测口径**：对成片按 **10fps** 抽帧，只测**中层主舞台 ROI（`y: 720–1866`，全宽）**的平均灰度绝对差 `roi_delta`；静止判据 **`roi_delta < 0.05`**（等价全屏 `< 0.025`）。任意连续静止窗 **`≤ 1.80 秒`**（片尾最终落幕最后 `1.5s` 除外）。
     - 旧的全屏口径（`delta < 0.15` / `≤1.20s`）已废止：2K 面积是 1080p 的 1.78 倍，全屏差被大片暗场稀释，会把「中层其实在呼吸」误判成死帧，进而倒逼代码加廉价扫光。
     - **严禁**为刷帧差给静止文字加微晃、加大旋转尘盘或短周期扫光。
   - 核心演化须用长尾曲线铺满主动演化阶段的 **`80%–95%`**；主体趋近定格时，摄影机缓推、微尘、光晕呼吸或线框自转不得同时刹停。
   - **复杂度分层**：过场幕 **`4.4–5.2s`**、2–3 步推导核心幕 **`5.8–7.2s`**、多阶段奇观幕 **`7.0–8.5s`**（奇观幕须拆 2–3 个递进动作阶段）。
   - **停顿**：推导步骤之间 **`0.65–0.85s`**；定型后思考窗 **`0.8–1.2s`**（文字与公式 100% 静止，仅纯几何/微光呼吸）；关键反转前 **`0.35–0.50s`** 蓄力。
   - **幕间干净接力**：非硬切幕按 §2.7 衔接（旧辅助元素先 `0.40s` 淡出清空，再滑入新结构）。
6. **同源物理声画咬合**：节奏、步进、计数、频率类片段，视觉加速度、光强脉动与音效须由同一时间函数驱动，毫秒级同步。
7. **持久舞台状态机与干净过渡**：
   - **单一持久状态机**：连续大幕由全局 `frame` 驱动；上一幕末帧的坐标/缩放/透明度与下一幕首帧严格相等（`===`），交界处跑 `seam_delta` 自检。
   - **区分 Morph 与 Clean Reset**：
     - **Morph（同系变形）**：同一拓扑家族的连续演化（点→线→坐标、方→立方、公式拆项），保持实体连续；
     - **Clean Reset（异构换场）**：拓扑完全不同的结构切换**严禁强留残缺旧边框做伪连续压叠**，须走四拍：
       1. 旧结构退净 **`0.40s`**（降对比 + 轻微散焦后淡出，不留残余边框）；
       2. 纯暗呼吸空拍 **`0.20–0.30s`**（只留底光与微尘）；
       3. 新主体先成型 **`0.45–0.65s`**（骨架先立住，此间**不出文字**）；
       4. 上层主句浮现 → 底部读数**滞后 `0.20–0.30s`** 淡入。
   - **背景不抢戏**：微尘 `opacity ≤ 0.08`，禁止旋转大尘盘；呼吸感只给纯几何线框、粒子、光晕。
   - **主舞台真实演规则**：核心数学/算法规则必须搬到中层**大尺寸演明白**，不许藏在底部小字里。
   - **干净过渡**：不把不同拓扑符号强扭成折断线；优先纤细通透线框；全片统一下标（字号/基线/字距/颜色）。
8. **具象交互的四段物理曲线**：
   - 双侧通透悬浮卡爪，只轻微收拢，不做夸张机械开合；
   - ① 预备收拢 + 离台微浮（投影随高度拉散）→ ② 三次贝塞尔弧线滑移（带轻量残影，禁直线平移）→ ③ 统一空间归属方向（禁中途反向穿帮）→ ④ 关联数字垂直滚轮滑切；
   - 四段按 §2.3 保留 `20%–30%` 重叠。
9. **环境光效速度与亮度硬上限**：
   - **台座/边框镜面流光**：单程扫掠周期 **`≥8–12 秒`**，2K 线速度 **`≤95 px/s`**；**单向慢掠后消隐**，严禁短周期来回往返扫；
   - **光带形态**：带宽 **`260–360 px`** 柔羽化，峰值不透明度 **`≤0.20`**；
   - **边缘/光晕呼吸**：周期 **`6–9 秒`**，幅度 **`±6%–10%`**，禁 `1–2s` 级快闪；
   - **互斥**：主体已有主动微动（2.5D 旋转/推进/材质高光巡游）时，底座禁止叠加额外扫光；
   - 同一幕只允许 **1 处**慢速光效在动。

## 三、视觉与排版：10 条

1. **双光学舞台（`lighting`，单条内统一）**：
   - **`studio_dark`（默认）**：底色 `#050608–#0B0A09`（默认 `#060709`），全片逐帧均值 **灰度 `<40` 占比 ∈ `[84%, 95%]`**；主字暖米白 `#F2EDE4`、核心亮线暖金 `#C9A96A`、次级读数冷灰 `#5C6370`；功能色 `≤4` 种且各绑语义；配定向柔光衰减、边缘高光与极微尘。
   - **`keynote_light`**：禁纯白/纯黑；底色 `#F4F2ED–#ECE9E2`（默认 `#F2F0EB`），**灰度 `>210` 占比 ∈ `[72%, 92%]`**；主字石墨 `#1C1C1E`、次级 `#6E6E73`、强调色 `≤4`；配环境遮蔽软投影与细腻反光。
2. **光学景深与静态文字零颤动**：
   - 前景微尘 / 焦点主角 / 远景空间三层；同屏只有 1 个视觉焦点；退居次要的图形用降对比 + `blur: 0→5px` + 微缩让位；**`blur` 禁用于前景可读文字**。
   - **零颤动**：主句与底部读数永久移出摄影机容器；入场只做纯 `opacity`；定型态 `transform: none; filter: none;` + 整数像素。
   - **文字四段式呼吸生命周期**（唯首幕第 0 帧直接满显例外）：
     1. **幕首留白气口**：`beatStart` 后留 **`0.35–0.55s`** 空镜/纯图形（大章节/大结构转折 **`0.60–0.85s`**）再起主句，此间不出任何新文字；
     2. **从容入场**：**`0.38–0.45s`** 纯 `opacity 0→1`（禁位移/缩放/散焦，整数像素）；
     3. **阅读定格窗**：**`0.90–1.25s`** 100% 全静态（`transform: none; filter: none; opacity: 1`），这是 `text_box_diff` 的唯一检测区间；
     4. **舒展尾迹出场**：**`0.60–0.72s`**，字间错峰 **`28–35ms`**、行间约 `60ms`，最右字先启程、向右上 `28°`；2K 位移 **`dx +214px / dy -114px`**，`easeInQuad` 起步，前 `35%` 维持 `0.88–1.0` 可见度；**必须在 `beatEnd - 0.15s` 归零**；
     5. **残影**：5 层定向模糊残影，独立时间包络 × 固定阶梯 **`0.46 / 0.30 / 0.18 / 0.09 / 0.04`**，**严禁与主字透明度二次相乘**；可加 3–4 条速度丝（按 §3.10 L3）。
   - **句间空拍**：上一句归零 → 下一句起句 ≥ **`0.50s`**（幕尾余白 `0.15s` + 幕首气口 `0.35s` 的下限组合）；同幕内上限 `0.90s`，超过即拖沓。
   - 中层数字/箭头/符号/层标禁止挂摄影机微推或 `sin(frame)` 漂浮；定型即 `clamp` 整数像素、`scale(1)`、`filter: none`。
   - 滚动数字用 `tabular-nums` + 固定绝对定位。
3. **2K 安全区与三段式构图**：
   - 安全区 **`x: 120–1212, y: 240–2000`**（1092×1760）；含引线端点、粒子尾迹、投影外扩都不得越界。
   - **上层叙事区 `y: 306–694`**：主行 `Bold 700` **`104 / 98 / 90px`**（`≤7 / 8–9 / ≥10` 字），色 `#F5F1E8`、关键词 `#E2C17A`；辅行 `Regular 400` **`76px`**，色 `#CCC6BB`；栈统一 `"Source Serif 4", "ChillJinshuSong", serif`；字距 `0.06–0.10em`、行高 `1.45`、单行 `≤12 字`、最多 2 行、每句 1 处高亮、无描边无底框；禁两行同字号同字重平铺；开场/高潮/片名卡可居中 **`y: 1040–1360`**。
   - **中西混排微距**：中文与西文/数字、数字与单位交界插 **`0.15em`** 视觉微间距（禁全角空格），确保 `(1, 2, 3)`、`1440×2560` 不糊成一团。
   - **中层主舞台 `y: 720–1866`**：与上下文字留白 **`≥106px`**；承载逻辑的标注用 `Noto Sans SC` **Medium `≥44–48px`**、亮度 **`≥#CFC7B8`**；标签置于净空区配短引线，不压台座斜边。
   - **下层读数 `y: 1880–1980`**：`JetBrains Mono` **`40–42px`**、`tabular-nums`、低对比；括号紧贴数字写 `(1, 2, 3)`。
   - 滚轮数字位套 `height: 1.15em; overflow: hidden` 裁剪框。
   - **零界面杂音**：无进度条、无字幕带、无角标、无套娃边框、无片头纯标题卡。
4. **分层视觉资产（`asset_layers`）**：
   - **`vector`**：可连续变形的数学级矢量；
   - **`3d`**：`@remotion/three` 或预渲染序列，真实材质（磨砂玻璃、哑光金属、受光曲面、线框）；
   - **`2.5d_parallax`**：远/中/近三层光影底景，代码驱动视差与统一色温，固定种子 + 资产清单，禁静态生图硬切拼贴。
5. **叙事文案与声学空间**：
   - **第 0 帧即入戏**：禁黑屏淡入；第 0 帧直接给第一幕悬念（≤14 字）与视觉锚点，`3.0–4.5s` 给第二拍转折；
   - 单幕主句 `6–18 字`（硬上限 22），全片 `220–420 字`；禁口播过渡词；结尾回扣开头 + 极简片名卡，禁求点赞关注；
   - **微音效**：只用人声以外的物理共鸣音色（泛音钟、低频脉冲、材质摩擦、与算法同源的乐音步进），禁 `whoosh/pop`；峰值 **`-16 ~ -12 dB`**；常规片 **`10–25 个`**；
   - **配乐**：由 `tools/mix_bgm.py` 卡 Drop 混入（基准 −13.5 dB，集成 −14~−18 LUFS），高潮前留 `0.4–0.6s` 动态洼谷；**全片 `[0.5s, total-2.0s]` 内不得出现 `>1.5s` 的 BGM 空白断层**。
6. **前景双层光学亮核**：暖白金实核 `#FFF6DF–#F0D594` + 低透明暖金外晕 `opacity 0.22–0.32`；禁单层粗重高饱和外发光。
7. **留白与图层丰富度**：
   - 单屏单一焦点不变；拒绝元素堆砌，也拒绝空洞线框；
   - 历史人物、经典手稿、奖项、实物可按需引入高品质图片层，**每片只选少数关键锚点**，且**阶段 1 完成版权与来源判定**；
   - 融底三要点：统一暗暖低饱和影调（暗部贴近 `#060709`）、四周径向羽化（禁矩形边框）、配极缓 2.5D 微推并叠矢量标线。
8. **具象道具精工渲染**：
   - **禁**扁平 SVG 多边形 + 均等线框硬凑；**禁**在实体道具正中叠发光小白点（双层光核只给抽象光点/节点）；
   - **推荐**：程序化 3D 高度场/法线 + GGX 高光离屏渲染透明 PNG 精灵（numpy + PIL，固定种子，按 2K 显示尺寸 `2×` 超采样，3–4 个肌理变体），再叠矢量轮廓高光。
   - **物理四件套**：冷暖材质分离；双层接触 AO（叠放投影、提离扩散）；克制台面微倒影（顶部 `opacity ≤0.14`）；非文字区纯光学微动（受 §2.9 约束）。
9. **字体（三档，禁跨层混用）**：
   - ① 叙事大字：中文 **寒蝉锦书宋 V2.0**（`ChillJinshuSong`，400/700，`github.com/Warren2060/ChillJinshuSong`）+ 西文/数字 **Source Serif 4**；栈 `"Source Serif 4", "ChillJinshuSong", serif`；
   - ② 盘面标注：**Noto Sans SC / Source Han Sans SC**（Regular/Medium）；
   - ③ 公式与读数：**JetBrains Mono** + `tabular-nums`；
   - 三套均 SIL OFL 1.1，可免费商用；**不绑定任何手机厂商字体**；阶段 1 须报备 `document.fonts` 实测生效的字体与字重；**禁静默回退** `Microsoft YaHei` / `STZhongsong` / `SimHei` / `SimSun`。
10. **2K 手机可见性线宽硬分级**：
    - 前提：6 英寸手机上等效约 360 CSS px，即 2K 按 **1:4** 缩小；`1–1.5px` 的线在手机上只有 `0.25–0.38px`，必然消失。
    - **L1 核心结构与关键特效**（主梁、配对弧、断裂高亮、核心箭头、光轨）：**`4.5–8.0px`**；可配 `16–26px / opacity 0.16–0.24` 柔光衬底；
    - **L2 交互控件与示意骨架**（卡爪主体 `4.0–5.0px`、拐角 `6.0–7.0px`、坐标轴、示意图、柱条边框）：**`3.5–4.5px`**；
    - **L3 辅助标尺/虚线/引线**：**硬下限 `≥2.5px`**（严禁 `1–1.5px`），不透明度 **`≥0.38`**；承载因果的次级连线 **`≥0.52`**；
    - **粒子 `7–12px`**、尾迹速度丝 **`3.5–5.5px`**；PBR 精灵 `2×` 超采样；
    - 暗场补偿：L2/L3 配合提亮 `+8%–12%`，禁只加粗不提亮；
    - 验收：阶段 1 的 360px 缩略图里 L1/L2 必须连续可辨、L3 不得消失。

## 四、6 条质量红线

1. **禁 PPT 翻页**：禁无拓扑延续的整屏淡出再弹窗；异构必须走四拍 Clean Reset。
2. **禁死帧卡顿**：中层 ROI 不得出现 `>1.80s` 的零运动段（`roi_delta < 0.05`；片尾最后 1.5s 除外）；**严禁**为刷帧差给文字加微晃或开短周期扫光。
3. **禁塑料霓虹发光**：禁高饱和单层粗重外发光；发光必须低透明多层指数衰减。
4. **禁默认裸字**：必须调字距/行高/字重反差；遵守 §3.2 四段式与零颤动。
5. **禁信息过载**：单屏只服务 1 个核心念头。
6. **禁画风拼贴**：引入 3D/2.5D 时，基底、光向、色温与代码层 100% 统一。

### 5.0 导出红线：2K 全平台硬解兼容 H.264

**唯一合法视频编码参数，逐字符固定**：

```bash
-c:v libx264 -profile:v high -level:v 5.1 -pix_fmt yuv420p -crf 16 -preset slow -g 120 -movflags +faststart
```

> **怎么落到命令行**：Remotion 4.0.545 的 CLI 只暴露 `--codec / --crf / --pixel-format / --color-space / --x264-preset`，
> **没有** `--level` 与 `--x264-params`。因此 `-level:v 5.1` 与 `-g 120` **无法靠封装改写**——
> `-c:v copy` 只搬运码流、不改 H.264 编码级别，必须真正重编码一次：
>
> ```bash
> ffmpeg -i out/raw.mp4 -c:v libx264 -profile:v high -level:v 5.1 \
>   -pix_fmt yuv420p -crf 16 -preset slow -g 120 -movflags +faststart out/final_video.mp4
> ```
>
> 另需 `--color-space=bt709`（`package.json` 的 `render:example` 已内置），否则 Remotion 默认输出 full-range `yuvj420p`，
> 不满足下面这条 `-pix_fmt yuv420p` 的兼容基线。
- **为什么必须是 `Level 5.1`**：`1440×2560` = `90×160 = 14,400` 宏块/帧；@60fps 即 **`864,000` 宏块/秒**。`Level 4.2` 上限 `522,240`（超规 65%），`Level 5.0` 上限 `589,824`（仍超规 46%），只有 `Level 5.1`（`983,040`）合法。写 4.2 / 5.0 会让严格解码器拒解或花屏。
- `-g 120` = 2 秒 GOP；**禁 `-g 1` / `keyint=1` 全 I 帧**，禁在 x264 参数里塞结构性 Hack（Remotion CLI 无 `--x264-params` 入口，此处指 ffmpeg 后处理阶段）。
- **绝对禁止**：`slice-max-mbs` 微分片、`slices=NN` 多片、全 I 帧、「按宏块对齐复制阅读窗像素」补丁。它们会让 **D3D11VA 把半屏解成 RGB(129,129,129) 纯灰块**——这是本规范 §5.6 存在的唯一理由。
- **体积自查**：标准档（`105–125s` / 2K / `crf 16`）约 **`18–65 MB`**（`0.006–0.02` bpp）。突然大一个数量级（>0.15 bpp）先怀疑编码 Hack。
- **音频**：终混 = 微音效 + 配乐，`AAC 256k / 48kHz stereo`；真峰值 `≤-1.0 dBTP`、集成 `-14~-18 LUFS`；**禁 `-an`**。
- 混音/封装一律 `-c:v copy`，绝不二次重编码画面。

### 5.0.1 2K 省盘渲染机制（强制）

2K 全片按 60fps 约 6,300–7,500 帧，整片 PNG 会占 12–18 GB。因此：

1. **流式直出**：Remotion 直接出 H.264（`remotion render --codec h264` / `renderMedia` 管道），逐帧编码、帧不落盘；**禁** `--sequence` 整片导出再二次编码。
2. **定点抽帧**：`text_box_diff === 0.000` 与 `seam_delta` 仍必须在 Remotion 无损 PNG 上实测，但只抽——每幕阅读窗 **3–4 帧**（窗首/中/尾）+ **每处非硬切交界成对帧**（上幕末帧 + 下幕首帧）；全片约 **120–180 张 / ~250 MB**。
3. **`.work/` 生命周期**：中间帧、抽帧、分段件、试编码件一律放本期 `.work/`；6 项验收全通过、成品与 `sfx_only.wav` 落盘后，**自动清理**。

### 5.1 ~ 5.6 六项硬验收

1. **规格与音轨（含音频零断层）**：`ffprobe` 实测 **`1440×2560` / `60fps` / `High@5.1` / `yuv420p`**；有有效音频流（非 `-an`）；真峰值 `≤-1.0 dBTP`、集成 `-14~-18 LUFS`；编码逐字符符合 §5.0；`encodingAudit` 无切片/全 I 帧告警。
   - **音频零断层**：`bgm_mix_report.json` 的 `bgm_gap_check` 必须 `pass: true`（`[0.5s, total-2.0s]` 内无 `>1.5s` 空白）；`climax_error_sec ≤ 0.03`。
2. **光场纯净度**：`studio_dark` 灰度 `<40` 占比 `[84%,95%]`；`keynote_light` 灰度 `>210` 占比 `[72%,92%]`。
3. **运动与稳定三合一**：
   - `beats.json`：`Σ durationSec ∈ [75,140]`（长片 `[140,240]`）、单幕 `≤22` 字、时长分层（`4.4–5.2 / 5.8–7.2 / 7.0–8.5`）、句间空拍 `0.50–0.90s`、步间 `0.65–0.85s`、硬切与音效数合规；
   - **ROI 零死帧**：10fps 抽帧，中层 `y:720–1866`，`roi_delta < 0.05` 的连续窗 `≤1.80s`（同时报告全屏 `<0.025` 作交叉参考）；
   - **`seam_delta`**：非硬切交界无重置尖峰；
   - **`text_box_diff === 0.000`**：只在 Remotion 无损 PNG（定点抽帧）上测，检测区间严格对齐阅读定格窗；禁在 H.264 成片上断言，禁为压误差改编码器。
4. **联系表与安全区**：元素在 `x:120–1212, y:240–2000`；无字压图/进度条/字幕带/卡片框/水印；L3 线宽 `≥2.5px`。
5. **事实闭环**：`facts_and_sources.md` 覆盖全部上屏数值、公式、史料与素材来源的一手 URL。
6. **硬解对拍（唯一成品跑 1 次）**：

   ```bash
   python tools/decoder_check.py --video <主题>.mp4 --output src/decoder_check.json --strict
   ```

   必须 `verdict: "PASS"` 且退出码 0：
   - D3D11VA vs 软解，原生 NV12 逐帧对拍：`maxFrameMAE = 0.0`、`maxSampleDelta = 0`；
   - 纯灰连通域：`grayLeftHalfMaxPct = 0.0` 且 `grayFullFrameMaxPct = 0.0`（判据：中性 RGB 极差 ≤20 + 中灰带 `Y 60–150` + 面积 ≥1% + 平坦 `std≤2`；暗场 `<40` 不计）；
   - `framesCompared == expectedFrames`；
   - **档位审计**：2K@60 必须 `High@5.1`，1080p@60 必须 `High@4.2`；分辨率/Level/profile 不符 = 硬失败；bpp / 切片数 / 关键帧占比告警必须为 0（`--strict` 会自动判 FAIL）。

## 六、强制两阶段交付

> 2K 全片渲染成本是 1080p 的 1.78 倍，返工代价更大：任何一条都必须先过低清快审。

### 6.1 阶段 1 · 核查与低清快审（强制停等）

**A. 写代码之前**
- 一手事实核查：每个上屏年份、研究者、文献、数值、公式都要可点 URL；
- **物理/力学隐喻自检**：天平、斜面、杠杆、卡爪、滚轮逐条问「方向对不对」——重的一侧是否真的下沉、倾斜是否与大小关系一致、抓取/释放因果是否反了；
- **档案/公版素材前置**：肖像、手稿、证书、实物照片，阶段 1 就完成来源与版权判定，并写入 `facts_and_sources.md`。

**B. 写完代码之后**
1. 只渲染前 `25–35s`：**`720×1280 @ 30fps`**，**直接带 BGM + SFX**（`mix_bgm.py --preview-duration 30`）；
2. 附非硬切交界 `seam_delta` 表、静态文字包围盒抽样；
3. 附 **2K 关键帧静图**（`remotion still` 无损 PNG）：核心道具特写 / 文字尾迹中段 / **中后段高潮结构**；
4. 附一张 **360px 逻辑宽的「手机实看缩略模拟图」**：关键帧 + 1 帧主舞台按 1:1 像素拼成对照条——看不清的线、糊掉的标注、过暗的层级，在这一步拦下；
5. **立即暂停等人工验收**，未点头不得进入阶段 2。

### 6.2 阶段 2 · 全片流式渲染与硬验收

1. 人工确认「连续丝滑、规则演明白、文字零颤动、气口不憋、线看得清」后，按 §5.0 流式渲染 **`1440×2560@60`**（`crf 16` / `-g 120` / `High@5.1`，禁 `-an`），帧不落盘；
2. 按 §5.0.1 定点抽帧，完成 `text_box_diff === 0.000` 与 `seam_delta`；
3. `tools/mix_bgm.py` 出**唯一成品** + `src/sfx_only.wav` + `bgm_mix_report.json`；
4. 跑齐 6 项验收，第 6 项对唯一成品跑 1 次 `decoder_check.py --strict`；
5. 全通过后确认成品与报告都在 `.work/` 之外且可读 → **自动清理 `.work/`**；
6. 未通过项如实报告并修复复验，不得宣称完成。
