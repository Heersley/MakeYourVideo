# 无声科普视听规范

每期使用同一份 [制作档案](../tools/profiles/) 和 [分幕](../tools/contracts/beats.schema.json)。档案的 `hard` 字段定义画幅、编码、光场、声音、运动、安全区、时长和硬解要求。

## 画面与声音

- 以中部图形推演为主。短主句、公式和读数服务于当前步骤，片名和环境光效保持克制。画面避免常驻角标、水印、进度条和底部字幕带。
- 用同一全局帧驱动连续舞台。同类对象通过连续形变接力，换到不同结构时让旧辅助元素先退净。相邻动作错开起势，留出阅读和思考时间。
- 摄影机只作用于动态几何层。定型的主句和标注锁定在整数像素，阅读窗内保持无损像素零差。使用[本地字体](../assets/fonts/FONT-NOTICE.md)。
- 使用无旁白的独立微音效和配乐。计数、步进等动作的音效跟随同一个时间轴，混音后核对覆盖、响度、真峰值和高潮卡点。

## 审片与取证

- 快审提供带声视频、道具特写、文字尾迹、高潮静帧和 360px 手机缩略图。
- 全片使用流式编码与定点无损抽样。非硬切交界要求 `seam_delta ≤ 0.01`、`max_pixel_delta ≤ 2`、变动像素占比 `≤ 0.01%`。阅读窗文字使用零差门槛。
- 正式交付核对编码、光场、运动与阅读窗、DOM 安全区和联系表、事实文件、D3D11VA 与软件解码对拍。取证和签字命令见[制作手册](PRODUCTION.md)。
