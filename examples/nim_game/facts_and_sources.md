## 异或与最高位验算

位权为 `4 / 2 / 1`。逐位规则为 `0⊕0=0`、`1⊕1=0`、`0⊕1=1⊕0=1`。每列将 1 两两配对，余下一个 1 时此位为 1。

| 局面 | 三行二进制 | 4 / 2 / 1 列中 1 的个数 | 异或和 |
|---|---|---|---|
| `(0,0,0)` | `000 ⊕ 000 ⊕ 000` | `0 / 0 / 0` | `000 = 0` |
| `(1,4,6)` | `001 ⊕ 100 ⊕ 110` | `2 / 1 / 1` | `011 = 3` |
| `(1,4,5)` | `001 ⊕ 100 ⊕ 101` | `2 / 0 / 2` | `000 = 0` |
| `(1,1,5)` | `001 ⊕ 001 ⊕ 101` | `1 / 0 / 3` | `101 = 5` |
| `(1,2,3)` | `001 ⊕ 010 ⊕ 011` | `0 / 2 / 2` | `000 = 0` |

1. **终点为零。** 全部堆空，轮到的一方无步可走，判负。
2. **零态必破。** 一次只改变一堆。旧值 `x` 与新值 `x′` 至少有一位不同。原异或和为零时，新异或和为 `x ⊕ x′ ≠ 0`。B19 中第二堆 `100 → 001`，4 列由 2 个 1 变 1 个，1 列由 2 个 1 变 3 个，得到 `101`。
3. **非零可归零。** 令 `S` 为当前异或和。找到 `S` 最高为 1 的位 `k`。该列有奇数个 1，必可找到某堆 `x` 的该位为 1。设 `x′ = x ⊕ S`，更高各位相同，该位从 1 变 0。低位最大回补为 `2^(k−1) + … + 1 = 2^k − 1 < 2^k`。当 `k = 0` 时低位为空和，仍有 `0 < 1`。因此 `x′ < x`，可以合法取走 `x − x′` 颗，且 `S′ = S ⊕ x ⊕ x′ = 0`。
4. **天平实例。** `S = 011 = 3`，选第三堆 `x = 110 = 6`。权值 4 不变，权值 2 从 1 变 0，权值 1 从 0 变 1，因此 `−2 + 1 = −1`，`6 ⊕ 3 = 101 = 5`。把第三堆减为 5 后，`1 ⊕ 4 ⊕ 5 = 0`。每步石子总数严格下降，必到全空终点。
5. **检算范围。** 独立按合法走法递归枚举三个堆各为 0–7 的 512 个局面，每个局面的胜负均与异或判定相符。归零走法有时有多种，例如 `(1,1,1)` 中取任一堆的唯一一颗都归零。

## B27 推广的边界与示例

定理适用的局面来自有限、无随机、双人轮流的公平组合博弈。给定同一个局面，双方的可走法相同，无步可走者负。每个局面在独立子局的和中等效于一堆尼姆，石子数为该局面的 Grundy 值。独立子局每步只选其中一个操作，组合值为各子局值的异或。三图到三堆的画面采用以下三个具体局面。 [Sprague 原文](https://www.jstage.jst.go.jp/article/tmj1911/41/0/41_0_438/_pdf) · [Grundy 原文](https://oeis.org/A002188/a002188.pdf)

| 图形 | 走法 | Grundy 值 |
|---|---|---|
| 方格棋盘 | 从 `(2,3)` 出发，每步只沿一条轴向原点移动任意正格。 | 等价于两堆，`2 ⊕ 3 = 1`。 |
| 分段直线 | 从位置 2 向左跳到任一更小的非负整数位置。 | 位置 0、1 的值为 0、1，`mex{0,1} = 2`。 |
| 分枝树 | 沿有向边从根走向一个后继。根有三个后继，值分别为 0、1、2。0 为叶子，1 只有一个 0 后继，2 有 0、1 两个后继。 | 根的值为 `mex{0,1,2} = 3`。 |

`mex` 是集合中缺少的最小非负整数。三个局面分别汇为 1、2、3 颗石子，承接 B28 的零态演示。
